Questions

What format are the books?

Each book is an A4 PDF, ready to print at home or school, with an EPUB version for tablets and e-readers.

Which book should I choose?

Flags of the World has every country in one book. The continent books add a full-page flag for every country, so there's more room to colour, and they're great for topic work on one part of the world.

Can I try a page first?

Yes. Every flag is also a free colouring page on FlagAtlas that you can print straight away.
